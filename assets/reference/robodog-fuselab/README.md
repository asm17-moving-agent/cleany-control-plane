# Fuselab Robodog reference media

Original-resolution media collected from the public Robodog project page for
internal design reference.

- Source: <https://fuselabcreative.com/our-projects/robodog/>
- Collected: 2026-08-31
- Contents: 16 source images, 7 extracted video frames, and 2 MP4 videos
- Responsive thumbnails and unrelated site-wide assets are excluded.
- Integrity hashes are recorded in `SHA256SUMS`.

The `intuitive-dashboard-interface-robodog-{0s,7s,14s}.png` files are
1600 x 1200 frame captures extracted from the correspondingly named MP4.
The `robodog-dashboard-ui-design-{0.5s,6s,9s,17s}.png` files are also
1600 x 1200 frame captures extracted from their correspondingly named MP4.
