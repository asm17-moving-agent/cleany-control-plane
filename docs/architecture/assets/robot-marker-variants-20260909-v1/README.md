# 지도 로봇 마커 시안 — 2026-09-09

원형 배경이 차지하는 면적을 줄이고, 작은 크기에서도 로봇을 식별할 수 있도록 만든 디자인 대안이다.
내장 `image_gen`으로 생성했다. 이 세션에는 Google Imagen 연결이 제공되지 않았다.

| 시안 | 방향 | 고려할 점 |
| --- | --- | --- |
| [01 · 탑뷰 마커](01-top-view.png) | 약 34×42px의 몸체 윤곽과 전방 표시 | 지도와 잘 어울리지만 브랜드 식별력은 약하다. |
| [02 · 미니 3D](02-mini-3d.png) | 약 42×48px의 배경 없는 로봇 형상 | 실제 외형을 유지하며, 작은 크기에서는 세부 형상 단순화가 필요하다. |
| [03 · 얼굴과 이름택](03-face-tag.png) | 약 28×28px 얼굴, 선택 시 이름·상태 라벨 | 기존 브랜드를 유지하면서 지도 가림이 적어 현재 화면에 추천한다. |

세 안 모두 원형 테두리와 큰 그림자를 제거하고, 이름은 기본적으로 숨긴다.
보이는 마커보다 클릭 영역을 넓게 잡아 작은 아이콘도 쉽게 선택할 수 있도록 한다.
이미지 아래쪽의 큰 표본은 비교를 위한 확대 예시다.

참조는 기존 18F 홈의 niri 캡처와 사용자가 제공한 로봇 관리 화면이다.
새로 첨부된 홈 이미지는 흰 화면이어서 이전에 확인한 지도 위 원형 마커를 대상으로 해석했다.
지도·문구·수치는 이미지 생성 과정에서 달라질 수 있으며, 실제 구현은 기존 지도와 계약을 따른다.
방향 표시와 위치는 실시간 연결이 검증된 데이터가 아니다. 이번 이미지들은 선택을 위한 시안이다.
