# Cleany 홈 진입점 시안 10종

운영자가 하루에 여러 번 방문해 일을 처리하는 홈 화면의 구성 비교용 이미지다. 내장 imagegen으로 생성하며, 모든 표시값은 데모 데이터다. 이번 시안의 기준은 여섯 업무 진입점과 그 진입에 필요한 요약정보를 명확히 보여주는 것이다.

## 공통 구성

| 진입점 | 기본 화면의 정보 | 액션 |
| --- | --- | --- |
| 작업 요청 | 개별 좌석의 책상 위 물체 정리 | 좌석 선택, 작업 요청 |
| 로봇 현황 | cleany-01, 작업 중, 배터리 82% 예시, 현재 12번 좌석 | 상세 보기 |
| 현재 위치 | D-HUB 위치와 지도, 갱신 시각, 예시 위치 표시 | 지도 보기 |
| 검토 사항 | 1건, 07번 좌석의 미처리 물체 확인 | 검토하기 |
| 요청 현황 | 진행 1건, 대기 2건, 다음 18번 좌석 | 요청 내역 |
| 최근 완료 결과 | 03번 좌석 완료 14:20, 선택적으로 09번 완료 14:05 | 결과 보기 |

상단 페이지 메뉴를 공통으로 사용한다. 전체 단계별 진행표, 열린 상세 요청 폼, 펼친 전후 사진과 긴 전체 대기열은 기본 화면에 두지 않는다. 위치 지도는 좌석 전체 번호를 나열하지 않는 개략도다.

## 제작 자료

- [공통 브리프](BRIEF.txt)는 사용자의 최신 논의와 여섯 진입점을 기록한다.
- [기존 홈 화면](reference/original-home.png)은 사용자가 첨부한 시설 도면과 제품 맥락 참조다.
- [상단 메뉴 참고](reference/top-navigation-reference.png)는 이전 imagegen 시안이다. 상단 내비게이션과 시각적인 톤만 참고한다.
- 생성본과 프롬프트는 비교 자료이며, 실제 앱 구현이나 로봇 측정 결과가 아니다.
- 정확한 지도 구조와 데이터 연결은 구현 단계에서 원본 지도 자산과 contracts를 따른다.
