# 로봇 얼굴 아이콘 5종 시안

2026-09-09. 사용자가 선택한 [기존 3안: 얼굴과 이름택](../robot-marker-variants-20260909-v1/03-face-tag.png)을 바탕으로, 지도 마커의 얼굴 아이콘을 다섯 방향으로 비교했다.

Built-in imagegen으로 각 시안을 개별 생성했다. 기존 Cleany 얼굴 브랜드 이미지와 선택된 3안 이미지를 참조했다.

| 번호 | 시안 | 특징 |
| --- | --- | --- |
| 01 | [기본형](01-classic-face.png) | 기존 얼굴과 가장 가까운 비율, 남색 테두리와 돌출된 노란 옆 탭 |
| 02 | [둥근형](02-soft-face.png) | 둥근 본체 안에 노란 옆면을 통합한 단정한 실루엣 |
| 03 | [와이드형](03-wide-face.png) | 낮고 긴 본체, 가로 눈으로 차분한 인상 |
| 04 | [각진형](04-chamfer-face.png) | 모서리를 깎은 장비형 실루엣 |
| 05 | [다크형](05-dark-face.png) | 남색 얼굴과 흰 표정의 강한 대비 |

다섯 안 모두 추가 원형 배경을 없애고 남색·흰색·노란색을 유지한다. 표현 비교상 02를 우선 추천한다. 노란 옆면이 본체에 통합되어 형태가 단정하다. 05는 밝은 지도에서 존재감을 더 강하게 주는 대안이다.

각 PNG는 큰 아이콘과 작은 반복 예시를 포함한 디자인 보드다. 보드의 28·40·56 표시는 생성 모델이 그린 크기 컨셉이며 실제 CSS 픽셀 크기를 검증한 결과가 아니다. 직접 배포하는 아이콘이나 확정된 브랜드 자산은 아니다. 실제 지도 적용 시 선택한 형태를 코드/SVG로 정리하고 실제 24–32px 크기에서 확인한다.

- [전체 생성 프롬프트와 참조 경로](prompts.json)
- [생성 원본 경로, 실제 이미지 크기, SHA-256](generation.json)

다섯 결과를 모두 시각적으로 확인했다. 원본은 생성 위치에 보존하고, 복사한 PNG의 바이트 일치를 확인했다. 이 작업은 시안 자산만 추가했으며 앱 코드와 계약은 변경하지 않았다.
