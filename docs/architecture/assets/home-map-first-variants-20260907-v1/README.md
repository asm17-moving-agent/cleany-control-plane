# 지도 중심 홈 시안 5종

내장 imagegen으로 생성한 디자인 검토용 이미지다. 로봇 목록을 항상 유지하고 지도 좌석을 작업 요청의 진입점으로 사용한다. 로봇 3대, 배터리, 위치, 요청과 결과는 모두 데모 데이터이며 실제 다중 로봇 기능의 구현을 뜻하지 않는다.

## 합의된 동작

- 로봇 목록은 이름, 상태, 배터리의 짧은 행으로 표시한다.
- 좌석 선택 시 오른쪽 패널에서 로봇, 명령, 우선순위를 지정하고 요청한다.
- 오른쪽 패널이 열려도 왼쪽 로봇 목록과 선택 좌석을 볼 수 있다.
- 로봇 문제의 즉시 조치와 작업 결과 검토를 구분한다.
- 요청 현황과 최근 완료는 요약에서 상세로 진입한다.

## 생성 자료

각 이미지와 같은 이름의 `.prompt.txt`는 정확한 생성 프롬프트이고, `.metadata.json`에는 원본 경로, 크기와 검수 기록을 둔다. [공통 브리프](BRIEF.txt)를 모든 시안에 적용한다. 참조 이미지는 기존 홈의 시설 지리만 참고하며 생성 지도는 측량 도면이 아니다.

이미지 생성과 검수만 수행한다. 앱 코드, API 계약과 KB는 변경하지 않는다.

## 최종 검수

최종 5장은 모두 1672×941 PNG다. 각 생성 원본과 저장본의 바이트 일치를 확인했으며 별도 비트맵 편집은 하지 않았다. 5장 모두 왼쪽 로봇 목록과 배터리, 지도 위치 마커, 후속 업무 진입점을 확인했다. 03과 05의 선택 좌석은 오른쪽 요청 패널과 일치하며 로봇·명령·우선순위 입력이 보인다. 04는 로봇 문제와 결과 검토를 구분한다.

일부 도면 기하와 좌석 배치는 시안마다 다르다. 03은 지도 옆 예시 위치 문구가 생략됐지만 상단 데모 표시가 있다. 05 하단 목록은 네 개의 작은 구획으로 생성됐다. 픽셀 단위 설계도보다 화면 구조와 상호작용 상태 비교를 위한 자료다.

[원본 시설 참조](reference/original-home.png), manifest.json, SHA256SUMS를 함께 보관한다. drafts 폴더에는 01과 02의 보정 전 이미지와 초기 프롬프트가 있다.
