# Cleany 홈 화면 디자인 시안 5종

KB 검토에서 확인한 개선점을 반영해 상용 관제 서비스의 홈 구성을 비교한 이미지 시안이다. 실제 기능이나 앱 코드에 적용한 결과는 아니다. 모든 이미지는 built-in imagegen으로 생성했으며, 생성·보정 프롬프트를 함께 보관한다.

| --- | --- | --- | --- |

## 공통 데모 상태

장소는 **부산 소마 센터 18층**이며, 단일 로봇 `cleany-01`이 하나의 활성 미션을 수행하는 상황이다.

| 대상 | 시안에 사용한 상태 |
| --- | --- |
| D-HUB 12번 | 현재 책상 작업 중 |
| D-HUB 18번·24번 | 대기 요청 2건 |
| D-HUB 07번 | 결과 확인 필요 1건, 미처리 내용 검토 |
| D-HUB 03번 | 최근 완료 결과 |
| D-HUB 21번 | 04 시안에서만 선택한 좌석. 요청을 아직 제출하지 않은 상태 |

`데모 데이터`, `예시 위치`, `배터리 미연동` 등의 표시로 표현의 성격을 구분한다. `관제 연결됨`은 관제 서버 연결 표시이며, 실측 로봇 위치나 배터리를 검증했다는 뜻이 아니다. 결과의 책상 전후 썸네일도 데모 이미지다.

## KB 개선점 반영

- 개별 좌석 선택과 `좌석 작업 요청`을 홈의 명확한 시작 동선으로 제시한다.
- 현재 미션의 외부 작업 단계인 요청·이동·책상 작업·복귀·결과를 표시한다.
- 단일 활성 미션과 다음 대기 요청을 구분해 보여 준다.
- 최근 완료 결과에서 전후 관찰, 미처리 내용과 확인 필요 상태를 살펴볼 수 있는 구성을 제안한다.
- 관제 서버 연결과 로봇의 실측 정보를 구분하고, 연동되지 않은 값은 실제 측정값처럼 표현하지 않는다.

생성 이미지는 구현 사양이 아니므로 정확한 도면·숫자·문구는 구현 시 `packages/contracts/`와 원본 자산을 따른다.

## 최종 검수 메모

- 최종 5장은 1672×941 PNG이며, 생성 후 별도 합성이나 업스케일 없이 원본을 복사했다.
- 01은 현재 화면을 확장하는 균형형 구성, 02는 현재 미션을 집중해서 관찰하는 구성으로 우선 비교할 만하다.
- 주요 미션 상태와 데모 표시, 요청 패널의 미제출 상태, 결과 사진의 처리 전후 차이를 시각적으로 확인했다.
- 01의 지도에는 15번이 16번으로 표시된 오류가 남아 있다. 다른 시안도 도면의 좌석 아이콘 수나 위치가 원본과 다를 수 있으므로, 지도 구현은 기존 자산과 좌석 계약을 기준으로 한다.
- 생성 및 보정 전 후보는 `drafts/`에 보존했다. 최종 선택 파일과 원본 생성 위치는 [manifest.json](manifest.json), 파일 무결성은 [SHA256SUMS](SHA256SUMS)에 기록한다.
