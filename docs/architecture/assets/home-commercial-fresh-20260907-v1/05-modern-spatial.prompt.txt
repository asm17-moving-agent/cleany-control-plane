Use case: ui-mockup. Create ONE polished Korean commercial robot operations web application screenshot, landscape 16:9 target 2048x1152. This is an original product design from functional requirements ONLY. NO reference images, no reproduction of any earlier dashboard, no browser frame, no device mockup, no collage. Brand Cleany. A believable carefully designed shipping B2B product, not generic AI dashboard cards.

FUNCTIONAL REQUIREMENTS:
Persistent LEFT sidebar showing concise robot list: name, operational state, battery. It remains visible even when a RIGHT contextual task-request panel is open. Center is an interactive office floor/seat map: seats are clickable to begin a mission; small robot markers show current locations. Seat selection opens RIGHT panel with selected seat, robot selection, command selection, priority, request submission. The map and selected seat remain visible alongside both sidebars. No separate giant task-request tile.
Robot condition and human attention: show immediate issues separately from result review; problem robot also highlighted in list. Include compact entry points to pending/active request status and recent completed results. Summaries and actions, not fully expanded reports or photo comparisons. Realistic hierarchy: operator notices problems, locates robot, clicks seat, configures task without leaving home.
Use three DEMO robots: 클리니 01 작업 중 82%, 클리니 02 대기 67%, 클리니 03 충전 중 24%; in incident variant replace03 with 이동 막힘 48%. Use small flat icons, never 3D robot illustrations. All synthetic data marked '데모'. Navigation in TOP header: 홈, 작업, 결과, 로봇. Location selector '부산 센터 · 18층'. Separate connection indicator '연결됨'. Avoid too many green badges.
Map must be designed anew as a plausible clean readable office schematic, NOT an architectural blueprint: spatial zones '라운지', '업무 공간 A', '업무 공간 B', '회의실', '충전 구역', corridors; muted non-operable rooms. Show 18-24 meaningful individual clickable seat rectangles, organized around shared desks and labeled compactly without duplicates. Map controls zoom, center robot; legend low contrast. Robot map positions have short names. Do not waste map on enormous empty space or utility rooms. Design geometry and iconography as if a professional UI team implemented SVG map layers.
Request panel when open: heading '작업 요청'; selected seat 'A-12'; robot selector '클리니 02 · 대기 · 67%'; command selector '책상 위 물체 확인 및 정리'; priority options '보통' and '높음'; CTA '요청 보내기'. A-12 must be highlighted in map with explicit selected label. No fullscreen overlay or scrim. No physical stop/remote motor control.
Common tiny operational summaries: '즉시 조치 0' (incident1), '결과 검토 1' with 'A-07 · 미처리 물체', '요청 현황' with '진행 1 · 대기 2', '최근 완료' with 'B-03 · 14:20'. Click affordances obvious but quiet. Every element has a purpose. Korean lettering exceptionally legible. Realistic desktop scale, disciplined typography and spacing, designed empty space, subtle borders. No marketing greeting/hero, huge KPI cards, gradients, glossy effects, arbitrary English headings, stepped workflow, before/after photos, numbered section headings, pie charts.

DESIGN DIRECTION:
MODERN SPATIAL. Premium contemporary light product, pale blue-gray canvas, white chrome, dark teal accent. LEFT fleet sidebar 220px ultra-compact name/state/battery rows. RIGHT request drawer OPEN 360px, subtly elevated, large typographic selected seat A-12 and compact aligned field labels. Map central: soft filled room polygons with nested shared desk islands and separate clickable seats, generous navigable corridors, exact consistent icon style. A-12 selected teal with short anchored label; map robots separate round icons with names. Follow-up entries in a single unified bottom drawer-like shelf (not separate cards) using three short columns results-review, request status, recent-complete; immediate-attention 0 is a quiet header badge. Sophisticated spatial editor feel, 8px radii, hairline separators and almost no shadows.
