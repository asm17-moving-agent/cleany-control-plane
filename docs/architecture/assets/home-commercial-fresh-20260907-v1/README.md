## 공통 요구사항

왼쪽 로봇 이름·상태·배터리는 항상 보인다. 지도 좌석을 선택하면 오른쪽에서 대상 로봇·명령·우선순위를 정해 요청한다. 즉시 조치, 결과 검토, 요청 현황, 최근 완료 결과에 접근할 수 있다. 큰 요청 카드나 전후 사진을 홈에 늘어놓지 않는다.

## 제작 자료

각 PNG와 같은 이름의 .prompt.txt는 정확한 생성 프롬프트다. 기존 이미지는 생성 입력으로 사용하지 않는다. 데이터와 시설은 데모이며 실제 제품 구현 또는 실측 지도와 다르다. 최종 이미지의 원본 경로, 해시와 검수는 manifest.json에 기록한다.

## 검수 결과

최종 5장은 1672×941 PNG이며 내장 imagegen 원본을 그대로 보존했다. 모든 안에 상시 로봇 상태, 지도 위치, 조치·검토·요청·완료 진입이 있고, 01·03·05는 A-12 선택과 요청 패널의 대상이 일치한다. 03·04의 조치 건수 불일치는 새 생성본 자체를 참조한 1회 보정으로 해결했다. 이전 대화의 이미지나 실제 시설 도면은 참조하지 않았다.

정확한 초기 프롬프트와 보정 프롬프트를 각각 보관한다. 01은 이미지 내 데모 배지가 생략됐다. 모든 시안의 수치·시설·명령 예시는 디자인 검토용 가상 데이터다. 세부 아이콘, 색상, 문구, 추가 메모 필드 등 생성 모델의 차이는 각 metadata 파일에 기록했다.
